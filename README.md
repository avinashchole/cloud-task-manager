# ☁️ Cloud Task Manager

A full-stack task management web application built using Flask and MySQL.

## 🚀 Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Task status management (Pending / Completed)
- Timestamp tracking
- Clean responsive UI using Bootstrap

## 🛠️ Tech Stack
- Python (Flask)
- MySQL
- Bootstrap 5
- HTML / Jinja2
- Git & GitHub

## 📂 Project Structure
cloud-task-manager/
│
├── app.py
├── templates/
│   └── index.html
└── requirements.txt

## ☁️ Deployment Plan
- Deploy on AWS EC2
- Configure Security Groups
- Add Nginx + Gunicorn
- Migrate database to AWS RDS
